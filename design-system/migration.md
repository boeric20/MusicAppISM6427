# Migrating from the current stylesheet

The site's `public/styles.css` declares 15 custom properties per theme, one shadow, one radius and one font stack. This table maps each to the new system so `styles.css` can be replaced by `tokens.css` plus `components/bundle.css` without touching `index.html` or `app.js`; every class name is kept.

| Source variable | Source light / dark | New token | Note |
| --- | --- | --- | --- |
| `--bg` | `#f4f3fb` / `#0f0e1a` | `bg` + the three `bg-tint-*` | Ground is now neutral with tints painted over it |
| `--surface` | `#ffffff` / `#17162a` | `glass` | Translucent, needs `blur-glass` |
| `--surface-2` | `#f0eefa` / `#1f1d35` | `glass-inset` | For inputs and nested cards |
| `--text` | `#15132b` / `#ecebf7` | `text` | Shifted to Apple-neutral ink |
| `--muted` | `#6b6886` / `#9c99b8` | `muted` | Darkened in light theme to hold 4.5:1 on glass |
| `--border` | `#e1deef` / `#2a2845` | `hairline` for dividers, `control-border` for controls, `glass-border` for surfaces | One variable became three roles |
| `--accent` | `#6d5dfc` / `#8f82ff` | `accent` | Moved toward system indigo; `accent-hover` added |
| `--accent-ink` | `#ffffff` / `#0f0e1a` | `accent-ink` | Unchanged pattern |

## Not carried over

- `.brand-mark` was a `linear-gradient(135deg, var(--accent), #c45dfc)` square. The system shows the actual mark instead; the gradient has no token.
- `.error` used `color-mix(in srgb, var(--danger) 30%, transparent)` for its border. Replaced by `danger-soft`.
- `--font` named Inter but the site never loaded it, so browsers already fell back to the system face. Nothing changes visually on that axis.

## Steps to apply

1. Link `tokens.css` (generated by this system) before `components/bundle.css` in `public/index.html`, or concatenate them into `public/styles.css`.
2. Replace the `.brand-mark` span with `<img class="brand-mark" src="/mark.svg" alt="">` and copy `assets/Logos/studio-suno-mark.svg` to `public/mark.svg`.
3. Keep the existing theme toggle: it sets `data-theme` on `<html>`, which is exactly what `tokens.css` reads.
4. Add `<meta name="theme-color">` entries for `bg` in each theme if you want the browser chrome to match.
