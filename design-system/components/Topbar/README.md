The sticky header: the mark and product name on the left, the credits pill and theme toggle on the right.

Use it once per page. It is `glass` with `blur-glass` and `shadow-glass`, borders removed on three sides so only the bottom `glass-border` reads as an edge. Padding is `space-3` vertical, `space-5` horizontal.

The consumer provides the mark (`assets/Logos/studio-suno-mark.svg` at 28px, `radius-sm`), the product name in `body-strong`, a StatusPill for the credit balance and one icon button for the theme toggle. Keep the right side to those two controls; anything else belongs in a panel.

Do not add a search field or navigation. The app has one screen.
