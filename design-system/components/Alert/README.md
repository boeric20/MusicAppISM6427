An inline error message shown above the action it blocks.

`danger` text at 14px/20 medium on `danger-soft`, with a `danger-soft` border, `radius-md`, `10px space-3` padding, `space-3` below. It carries `role="alert"` and stays `hidden` until it has text, so screen readers announce it when it appears.

The consumer provides one sentence that names the problem and the fix. There is no success or info variant: success is shown by the Ready badge, information by hints.
