An on/off toggle with its label to the right, used for Instrumental in the composer and the extend dialog.

Track 42 by 26px, `radius-pill`, `glass-inset` with `control-border` when off and `accent` when on. Thumb 18px in `knob` with `shadow-control`, moving 16px on `duration-base`. Label in `body-strong`.

The consumer provides the checkbox input and the label text. Use a switch only for a setting that applies immediately to the next action; a choice between several values is a select.
